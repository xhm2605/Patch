Space Theme Sprite Replacements for Unity

These PNG files match the original asset file names and pixel dimensions.

1. Back up your Unity project.
2. Replace the original PNG sprite files with these files under the same paths in your Unity Assets folder.
3. DO NOT replace/delete the original .meta files, prefabs, or scripts.
4. Allow Unity to reimport. If needed, set Texture Type: Sprite (2D and UI), Filter Mode: Point (no filter), Compression: None.
5. Verify sprite pivot, SpriteRenderer settings, animation clips, and collider fit in Play mode.

These are downscaled interpretations of the concept art; inspect their small-scale readability.
