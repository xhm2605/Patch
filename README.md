# Patch
PATCH Unity Game Project

## Installation

download the build from github

## Feature:
- this is the game that contant 5 mini game which is Pac-Man, Donkey Kong, Snake, Super Mario Bros, and Space Invaders. 
- To win the game, Player will need to finish 5 mini games which will gives player parts to repair the spaceship.
- There are 3 difficulty mode, each one will generate more enemy to make games harder.
